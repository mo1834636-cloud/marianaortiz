# Mi primer repositorio y sitio publicado con GitHub Pages

Sitio web personal de **Mariana Ortiz Ortiz**, estudiante de segundo semestre de Ingeniería de Sistemas de la Universidad Francisco de Paula Santander Ocaña (UFPSO).

## Descripción

Este repositorio corresponde al trabajo escrito del Primer Parcial de la asignatura Mantenimiento de Computadores y Desarrollo de Aplicaciones Web, orientada por el docente Jose Janer Barbosa León. El proyecto aplica el control de versiones con Git, el uso de GitHub como repositorio remoto y la publicación de un sitio estático con GitHub Pages.

## Sitio publicado

https://mo1834636-cloud.github.io/marianaortiz/

## Estructura del repositorio

| Archivo | Función |
|---|---|
| `index.html` | Página principal del sitio |
| `README.md` | Descripción del proyecto |
| `_config.yml` | Configuración de Jekyll (título, descripción y tema) |

## Comandos Git utilizados

```bash
git init
git add .
git commit -m "Primer commit: sitio web personal"
git branch -M main
git remote add origin https://github.com/mo1834636-cloud/marianaortiz.git
git push -u origin main
```
