Lo que he aprendido

Git

Sistema de control de versiones distribuido que registra cada cambio de un proyecto y permite volver a versiones anteriores.

GitHub

Plataforma en la nube donde se alojan repositorios Git para compartirlos y trabajar en equipo.

GitHub Pages

Servicio gratuito que publica sitios web estáticos directamente desde un repositorio.

Comandos que usé

  • git init crea el repositorio local.
  • git add . prepara los archivos para la confirmación.
  • git commit -m "mensaje" guarda los cambios en el historial.
  • git remote add origin URL enlaza el repositorio local con GitHub.
  • git push -u origin main sube los cambios al repositorio remoto.
